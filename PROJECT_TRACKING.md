## 🚀 Quick Start for Team Members

### Setup
1. Clone repo: `git clone https://github.com/YOUR_USERNAME/plant-disease-yield-prediction.git`
2. Install requirements: `pip install -r requirements.txt`
3. Run training: `python src/train_keras_models.py --person [zahra|sireen|tala]`

### Model Assignments
- **Zahra**: ResNet family, VGG, Xception, Inception, MobileNet, NASNetMobile
- **Sireen**: EfficientNet B0-B7, EfficientNetV2 B0-L
- **Tala**: DenseNet, ConvNeXt, NASNetLarge, MobileNetV3
